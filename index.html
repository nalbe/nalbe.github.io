Featured Projects

  • IPushButton Library

    A lightweight, zero-allocation Arduino library for robust button input handling. Solves real-world hardware input problems with elegance and efficiency:

    • Advanced debouncing

      Combines hardware timing checks with software smoothing to completely eliminate erratic button behavior and contact bounce.

    • Rich event detection

      Reliably recognizes distinct interaction patterns: single clicks, long presses, double clicks, and rapid sequences.

    • Seamless integration

      Minimal setup with clear, well-documented example sketches for immediate use in any Arduino project.

  • IKeybind Library

    An advanced Arduino keybind handler built on top of IPushButton, designed for multi-key combinations and complex event-driven input scenarios:

    • Multi-key combinations

      Define combinations of two or more physical buttons, assigning modifier and trigger key roles. The last pin in a combination acts as the trigger while others serve as modifiers.

    • Event state detection

      Each combination can fire on specific trigger key states: release, rapid (rapid press), or hold. Enables rich input patterns from a minimal number of physical buttons.

    • Compile-time configuration

      Leverages C++ templates to define the number of keys and events at compile time (IKeybind<Key_Cnt, Event_Cnt>). Ensures zero dynamic memory allocation, making it ideal for resource-constrained microcontrollers like AVR.

    • Modular architecture

      Initialized directly with an array of IPushButton objects. Supports per-key configurations like repeatDelay() via forEachKey(). Simply call kb.update() in your main loop and check events with kb.isEvent(index).
