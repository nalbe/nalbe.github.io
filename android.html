Android work

GSI · Magisk · KernelSU

Modules and patches that make GSI ROMs behave on the Blackview Shark 8 (MediaTek MT6789, stock vendor). All Magisk / KernelSU based, tested on Android 13-14 builds.

← Back to main page
shark8-volte-vowifi-gsi-patch Smali

Framework smali patch that brings VoLTE + VoWiFi (IMS) back on the Shark 8 (MTK MT6789, phh GSI Android 14, MegaFon).
shark8-led-daemon C

Native root daemon (chgd) + optional LED GUI driving the notification / charge LED on the Shark 8 GSI - notifications arrive over the standalone noty-bridge app, no polling loops.
android-aw2033-driver C

Standalone AW2033 RGB LED chip controller: register map + on-chip pattern engine, and the awctl CLI for hand-tuning the LED on-device. The LED daemon links it as a static library.
android-notify-bridge Kotlin

Headless NotificationListenerService that routes Android notification events (posts, calls, VoIP, screen, light toggle) to any consumer over abstract Unix sockets - config-driven rules and sinks, decoupled from the LED daemon.
shark8-stock-camera-gsi-port Java

Patched stock camera APK for the Shark 8 GSI - restores HDR, Night and Panorama by bundling the original ArcSoft native libs.
shark8-vulkan-gsi-patch Shell

Magisk module forcing Android HWUI rendering onto the Vulkan backend (ro.hwui.use_vulkan=true) for the Shark 8 GSI.
shark8-gsi-logspam-cosmetics Shell

KernelSU module silencing SELinux avc find/getattr logspam and ImsProvisioningController noise from GSI/vendor mixing.
shark8-adb-wifi-lan-persistent Shell

KernelSU module keeping ADB alive over Wi-Fi on port 5555, firewalled (iptables) to your LAN subnet only.
shark8-custom-bootlogo PowerShell

Custom boot logo (splash) for the Shark 8 - MTK lk logo partition image builder and flasher, flashable zip included.
shark8-audiovol-earpiece-fix XML

Fixes the weak call earpiece on the Shark 8: repairs a broken factory dl_gain curve in SpeechVol_AudioParam.xml (WB/RCV/GSM, param_id 11) and shows how to apply it on KernelSU.
shark8-gamemode-gsi Shell

KernelSU module + diagnostic kit that brings the stock MTK game mode back on the Shark 8 (Helio G99) AOSP/PHH GSI - re-supplies the framework trigger (IMtkPower::notifyAppState) so the vendor power engine applies its stock per-app profiles again. Pure trigger, no binary patches.
shark8-smartrefresh-gsi Shell

KernelSU module + diagnostic kit that fixes visible screen tearing at 120Hz on the Shark 8 GSI - kills the SF content-detection churn that re-applies the display mode every ~200-400ms and replaces the broken MTK dynamic-FPS with a clean touch-driven 60/120 Hz governor.
